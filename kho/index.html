Chìa khoá GitHub trên máy này

Chỉ máy dùng để duyệt mới cần chìa khoá. Máy chỉ để chơi thì không cần. Chìa khoá chỉ nằm trong trình duyệt của máy này, không gửi đi đâu ngoài GitHub.

Cách tạo chìa khoá (làm một lần)

Làm trên máy tính hoặc iPad, mở bằng Safari/Chrome, đã đăng nhập GitHub tài khoản frioscrt. Chìa khoá này chỉ được ghi vào đúng repo msclair, không đụng được repo khác.

  1. Mở trang tạo chìa khoá mới của GitHub (bấm vào chữ xanh này, tớ đã gắn sẵn link). GitHub có thể hỏi lại mật khẩu, cậu cứ nhập.
  2. Ô Token name: gõ tên dễ nhớ, ví dụ Kho game iPad.
  3. Ô Expiration (hạn dùng): chọn 1 year hoặc Custom rồi chọn ngày xa nhất. Hết hạn thì làm lại các bước này.
  4. Mục Repository access: chọn Only select repositories, rồi bấm ô Select repositories và chọn frioscrt/msclair.
  5. Mục Permissions → Repository permissions: tìm dòng Contents, đổi từ "No access" thành Read and write. Các dòng khác để nguyên (dòng Metadata tự thành Read-only, không sao).
  6. Kéo xuống cuối, bấm nút xanh Generate token, rồi bấm Generate token lần nữa nếu GitHub hỏi lại.
  7. GitHub hiện một dãy chữ bắt đầu bằng github_pat_. Bấm nút chép (hình hai tờ giấy) cạnh dãy đó. Dãy này chỉ hiện một lần.
  8. Quay lại trang kho này, mục Chìa khoá, dán vào ô ở trên (chạm giữ vào ô → Dán), bấm Lưu và thử chìa khoá. Hiện chữ xanh "Chìa khoá dùng được" là xong.

Đừng gửi dãy chữ này cho ai, kể cả dán vào chat với Claude.

Khi mất máy hoặc lỡ để lộ chìa khoá

  1. Mở trang danh sách chìa khoá của GitHub.
  2. Bấm vào tên chìa khoá (ví dụ "Kho game iPad"), kéo xuống cuối, bấm Delete rồi xác nhận. Chìa khoá hết tác dụng ngay, kể cả trên máy bị mất.
  3. Muốn duyệt tiếp trên máy khác thì tạo chìa khoá mới theo các bước ở trên.

Chỉ thôi dùng một máy (không mất) thì bấm "Xoá chìa khoá khỏi máy này" ở trên là đủ.
